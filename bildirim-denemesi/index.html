Bu düğme bildirimi telefonun kendisinde gösterir (internetten gelmez); sadece sesi ve titreşimi denemek içindir.

2. Telefon ayarları (bir kez)

  1. Chrome menüsü (⋮) → Ana ekrana ekle / Uygulamayı yükle.
  2. Ayarlar → Uygulamalar → Chrome → Pil → Kısıtlanmamış.
  3. Ayarlar → Uygulamalar → Chrome (ya da yüklenen uygulama) → Bildirimler: bu sitenin bildirimleri açık, önem Acil / sesli.
  4. Zil sesi açık, Rahatsız Etmeyin kapalı. Web bildirimi sessiz modu aşamaz.
  5. Kilit ekranında bildirimler gösterilsin (Ayarlar → Bildirimler → Kilit ekranı).
  6. Xiaomi / Oppo / Huawei ise: Chrome için otomatik başlatma ve arka planda çalışma izni.
